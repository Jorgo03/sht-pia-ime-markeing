# sht-pia-ime-markeing

Marketing videos for **Shtëpia.ime**.

- **[`Shtepia-ime-Creative-Studio/`](Shtepia-ime-Creative-Studio/README.md)** — the motion-graphics and automated video production kit (HyperFrames): 6 creative modes, 62 scenes, 12 campaign templates, original sound design, voice studio, quality control, multi-format export.
- **Sample films:** `Shtepia-ime-Creative-Studio/exports/*/` (MP4 + caption + storyboard + QC report).
- **With Claude Code:** describe the video in one sentence; the `/shtepia-video` skill plans it, waits for your approval, then renders, checks and exports it.

```bash
cd Shtepia-ime-Creative-Studio && npm install && npm run setup
npm run video -- why-shtepia-ime
```
